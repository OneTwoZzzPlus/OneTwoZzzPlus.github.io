LibreSpeed via Docker Compose [2026]

Nginx BashOps PostgreSQL S3 Storage Docker Compose
Репозиторий инфраструктуры • Оригинальный LibreSpeed
  • Инфраструктура как код (IaC). Успешно мигрировал систему с классических systemd-юнитов на Docker Compose. Реализовал конфигурацию через .env, упорядочил запуск сервисов с помощью healthcheck и depends_on.

SSO Auth Service [2025]

Go gRPC Next.js TypeScript PostgreSQL Docker Compose
Репозиторий проекта
  • Архитектура и бэкенд. Разработал микросервисную систему сквозной аутентификации и авторизации (SSO) на Go. Архитектура приложения включает в себя gRPC-сервер для быстрого межсервисного общения, REST Gateway для обработки внешних HTTP-запросов и SMTP-модуль для отправки сервисных писем.
  • Интерфейсы и протоколы. Спроектировал строгие контракты взаимодействия между компонентами на базе Protocol Buffers. Настроил скрипты автоматической генерации кода (Protobuf) и интегрировал gRPC-web клиент для прямой связи клиентской части с бэкенд-сервисами.
  • Frontend. Создал пользовательский веб-интерфейс на TypeScript и Next.js с динамическими формами авторизации и регистрации, отправляющими строго типизированные gRPC-запросы напрямую в микросервисы.
  • Инфраструктура и хранение. Организовал реляционное хранилище пользователей и прав доступа на базе PostgreSQL. Полностью контейнеризировал систему, настроив запуск и автоматическую сборку изолированных окружений фронтенда, бэкенда и базы данных через Docker Compose.
